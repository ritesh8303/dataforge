\section{Architecture (logical)}
\label{sec:architecture}

\begin{lstlisting}[caption={Logical architecture of the AI integration layer},label={lst:arch}]
Public JDs -> Ingest -> Bronze -> Silver (SCD2, is_tech, rules fields)
                              |
                         Gold marts + Jobs/Metrics APIs + Pages
                              |
              [optional] Enrichment (rules -> Bedrock) -> ai_enrichment + embeddings
                              |
User / MCP -> Match Function URL (FastAPI) -> hybrid retrieval -> citations
                              |
                    [optional] multi-agent graph (bounded) -> HITL
\end{lstlisting}

Orchestration proofs: EventBridge + Lambda (production), Step Functions Express Silver$\rightarrow$Gold (thin proof), Airflow DAG in Docker (keyword proof, not MWAA).

\section{Design principles}

\begin{enumerate}[leftmargin=*]
  \item \textbf{Additive, not invasive} --- AI columns join; SCD keys immutable.
  \item \textbf{Rules before tokens} --- save Bedrock for ambiguity.
  \item \textbf{Measure before marketing} --- CI evals; non-saturated gold set.
  \item \textbf{Bound agents} --- fixed handoff/LLM caps.
  \item \textbf{Transparency} --- citations, disclaimers, OpenAPI.
\end{enumerate}
