\paragraph{Interpretation.}
Dense retrieval outperforms the heuristic wizard on nDCG@10 (\textbf{H1 supported} on this gold set). Hybrid trails pure dense on this particular label distribution but remains the \textbf{product default} because Match also emphasises lexical fallback, filterability, and citation workflows that combine lexical hits with structured JD evidence. Scores are intentionally \textbf{non-saturated} (unlike trivial demos with nDCG$\approx$1.0).

\section{Multi-agent ablation (thesis-plus)}

On the local provider, average citation \textbf{structure} validity was 1.0 for both hybrid single-shot and multi-agent (30 queries). This indicates the schema/citation contract is enforced, but \textbf{faithfulness} under Bedrock still requires a post-quota spot-check (local saturation does not prove semantic grounding).

\section{Threats to validity}

\begin{itemize}[leftmargin=*]
  \item Label set size (42$\times$96) is adequate for an applied MSc pilot, not an industrial IR benchmark.
  \item Dense advantage may partly reflect label construction; hybrid product choice is multi-objective.
  \item ROI uses public pricing assumptions until live CostLogger traces accumulate.
  \item RQ2 live cells incomplete pending quota.
\end{itemize}
