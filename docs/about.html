Portfolio · UE M.Sc. thesis reference

Problem → pipeline → AI → bio

Public job boards bury fresher, Werkstudent, internship, and thesis openings in data / AI under mid/senior and non-data noise across the EU. DataForge gates Gold / Jobs / Match to that audience and adds an advisory match surface. We only use legal public APIs and ATS feeds — never LinkedIn or workingstudentjobs.de scrapes.

1. Pipeline

  • Bronze → Silver (SCD2) → Gold on AWS S3 (eu-central-1)
  • Sources: Arbeitnow, BA, EURES, ATS/Personio, Berlin startups (optional Himalayas / HN)
  • Product gate: EU × data/AI fields × early-career only; ambiguous rows → ingest review queue
  • dbt + DuckDB on Gold aggregates; quality gate in CI

2. AI matching (frugal)

  • Rules-first enrichment; Bedrock Nova / Titan when ambiguous
  • Hybrid BM25 + dense (LanceDB-on-S3 helper) + RRF
  • FastAPI Match API with PII redaction and cited job_id explanations
  • Optional multi-agent graph (Supervisor → Retriever → Scorer → Explainer → Critic) + MCP tools
  • Kill switch, daily € budget, HITL queue for low confidence

3. Honest limits

Visa flags are advisory, not legal advice. Match URLs go live only after terraform/ai.tf is applied. See RESPONSIBLE_AI.md and the living ROADMAP.
